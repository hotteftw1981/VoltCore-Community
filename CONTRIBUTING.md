# Contributing to VoltCore Community

Thank you for your interest in VoltCore Community!

**Publication preparation:** This repository is not yet open for general external contributions. The planned public license is GNU AGPL v3 only; the final rights and publication review is still pending.

## Before submitting code
- Open an issue to discuss significant changes.
- Never submit secrets, production data, private charging records, third-party copyrighted material without compatible permission, or code copied from VoltCore Pro/Cloud.
- Your contribution must be your own work or used with appropriate rights; list any third-party components and their licenses.
- Keep contributions focused, document configuration changes, and add regression coverage where appropriate.

## Commercial-licensing boundary
VoltCore Community is intended to remain open source; VoltCore Pro and VoltCore Cloud are separate commercial products. **AGPL contribution alone does not grant the project owner an unrestricted right to relicense third-party contributions into proprietary products.**

Until a contributor-rights policy is finalized, please **do not submit external code pull requests**. Bug reports, reproducible issues and documentation corrections can be discussed first. If later dual licensing is desired, a properly reviewed contributor license agreement or equivalent express permission must be established before taking code for proprietary use.

## Security
Do not disclose exploitable vulnerabilities with full details in public issues. Contact the maintainer through a private channel or GitHub private vulnerability reporting when available.
