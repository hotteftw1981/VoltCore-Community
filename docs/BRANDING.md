# 🎨 VoltCore Community Branding

This document defines the initial visual identity for **VoltCore Community**.

## 💙 Brand family

VoltCore Community uses the shared VoltCore visual language:

- **VC monogram**
- integrated **electric plug** inside the C
- deep navy + electric blue palette
- clean, modern software-oriented typography
- transparent master logo assets for flexible placement

The Community edition keeps the main VoltCore identity and uses **COMMUNITY EDITION** as the edition label.

## 📁 Included assets

Runtime assets live in:

`app/static/branding/`

Included files:

- `voltcore-community-horizontal.svg`  
  Primary horizontal logo for light surfaces.

- `voltcore-community-horizontal-dark.svg`  
  Horizontal logo optimized for dark surfaces.

- `voltcore-community-stacked.svg`  
  Stacked logo for splash screens, cards and narrow layouts.

- `voltcore-community-icon.svg`  
  Transparent VC monogram without surrounding app tile.

- `voltcore-community-app-icon.svg`  
  Rounded-square app icon.

- `app/static/favicon.svg`  
  Browser favicon using the Community app-icon design.

## ✅ Usage rules

- Prefer the transparent SVG assets over raster screenshots.
- Use the normal horizontal logo on light surfaces.
- Use the dark-surface version on charcoal / near-black backgrounds.
- Use the standalone VC icon for compact navigation, small UI surfaces and technical branding.
- Use the rounded app icon for favicon, PWA and launcher contexts.
- Keep sufficient whitespace around the mark.
- Do not stretch, skew, recolor or rebuild the mark independently inside product templates.

## 🌙 Dark mode

Dark mode uses the same family mark, but the word **Volt** switches to a light tone while **Core** remains electric blue. This preserves recognition and contrast.

## 🔌 Edition naming

The logo should present the product as:

**VoltCore**  
**COMMUNITY EDITION**

The edition label remains visually secondary to the VoltCore master brand.
